# ATLAS marker glyphs

Generated assets for globe pins (hazards, tracks, reference). Do not edit by hand.

```bash
npm run icons          # pull + build
npm run icons:pull     # Iconify CLI / API → scripts/.icon-cache/
npm run icons:build    # normalize → *.svg + glyphCatalog.js
```

Manifest: `scripts/atlas-marker-icons.txt`
