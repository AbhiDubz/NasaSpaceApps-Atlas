## 3D emoji assets generator (inspiration)

Pin-shaped GLB generation follows the approach of
[wangyz1999/3d-emoji-assets-generator](https://github.com/wangyz1999/3d-emoji-assets-generator)
(MIT): Twemoji-aligned hazard families + Three.js + GLTFExporter pin meshes.

ATLAS regenerates meshes via `npm run hazards:glb` (`scripts/hazard-glb/`).
See `public/models/hazards/ATTRIBUTION.txt`.
